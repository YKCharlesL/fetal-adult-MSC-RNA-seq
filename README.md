# Fetal vs Adult MSC RNA-seq Analysis

## Overview
This repository contains the RNA-sequencing analysis pipeline and notebooks 
comparing gene expression profiles between fetal and adult mesenchymal 
stem cells (MSCs) throughout osteogenic differetiation

## Citation
As part of submission for manuscript "From Development to Differentiation: A Comparative Study of Fetal and Adult Mesenchymal Stem Cells in Bone Formation"
